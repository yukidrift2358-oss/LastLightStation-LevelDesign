# 《长夜泊站》v1—v6 版本更新记录

整理日期：2026年10月21日

项目从单层环状流程原型，逐步发展为具有三层交织动线、支线顺序选择和环境叙事的第三人称动作探索白盒。六个版本依次处理流程衔接、楼层与挑战配置、技能反馈与指路、攻击故障、角色动画，以及跨层入口和支线顺序。

## v1｜基础流程原型

**版本重点：先建立能够从教学走到结局的完整关卡。**

- 搭建“线性教学 → 单层12扇区圆环 → 圆形Boss场地”的基础流程。
- 实现第三人称移动、跳跃、闪避、基础攻击与交互。
- 建立电力分流、气密隔离、Q抑制三项核心机制，并在教学后安排组合运用。
- 使用邻接侧门与正对面旋转桥，组织覆盖各扇区的受控推进路线。
- 加入任务记录、检查点、地图与Boss流程，以配给、隔离授权和生活遗留物铺设空间站悲剧背景。

这一版主要确认流程和规则能否相互衔接，为后续空间与体验迭代提供基础。

## v2｜三层圆环与挑战扩展

**版本重点：让不同楼层承担不同的学习任务，并增加战斗与移动的变化。**

- 将单层圆环扩展为6区生活环、12区工业环、8区隔离环，共26个环区，再接Boss舱。
- 按“基础机制验证 → 强化运用 → 综合考验”配置三层内容。
- 扩展为冲锋体、射线哨兵、维修机、牵引机四种敌人行为，用冲锋、视线、支援和位移压力区分应对方式。
- 加入约3米高的服务步道、坡道与高低位遭遇，并使用两部观景升降台连接楼层。
- 增加继电器顺序、短时出口窗口和先隔离再供电、最后抑制的组合条件。
- 调整为九处安全房，进入后恢复生命与技能，在挑战之间提供阅读、回望与恢复空间。

这一版建立三层规模与难度分工，主线仍主要按楼层依次推进。

## v3｜模型替换、Q反馈与动态引导

**版本重点：让玩家看得懂威胁、技能差异和下一步行动。**

- 引入Quaternius科幻机械模型，替换敌人、Boss及部分桌椅、储物柜、货箱、医疗道具等占位外观。
- 为射线与维修眼球分别配置红色镜头、青色维修光环，改善共用基础模型时的辨识度。
- 将Q明确区分为短按松开的快速抑制，以及蓄满1.2秒后松开的重抑制：前者9米／4秒，后者16米／7秒，并配置不同冷却。
- 增加蓄能百分比、金色范围圈、就绪提示音与不同释放反馈；暂停、地图、阅读和死亡会取消未释放的蓄能。
- 加入青色流动灯带与金色目标端点，依据当前任务状态指向操作点、出口、桥或升降台。
- 让引导依据真实楼板、门、障碍与坡道寻找可走路径，修正穿墙、误用桌柜顶面以及高台目标引导问题。

这一版把推进信息落到场景中，减少玩家因目标或反馈不清而停滞。

## v4｜白模持刀角色与眼球敌人修复

**版本重点：让攻击动作和敌人威胁具有可信的表现与结果。**

- 将原胶囊外观替换为原创白色关节人形，加入持刀、行走、蓄能与挥刀的程序关节动作。
- 为挥刀设置起手、接触、刀光与收招阶段，使伤害在接触时刻结算，并在重生或禁用时取消未完成攻击。
- 定位上层红镜头哨兵射线被平台遮挡的问题，将其移至平台前缘，恢复向下层目标的有效攻击，同时保留真实掩体遮挡。
- 为射线增加可见光束及供电、断电、抑制状态反馈。
- 保留维修机优先治疗同伴的职责，并增加没有待修复目标时的弱自卫射击，改善“眼球似乎不会攻击”的理解落差。
- 将回归检查从观察预警扩展到实际伤害、掩体阻挡、断电与抑制效果。

这一版修正了“看起来在攻击，实际上没有形成威胁”的问题。

## v5｜蒙皮白模与导入动画完善

**版本重点：在保留原有操作规则的基础上，提高角色动作表现的完整性。**

- 换用经确认的Quaternius白色蒙皮人形，保留白色外壳、深色关节与手指骨骼的造型。
- 接入持刀待机、行走、奔跑、空中、闪避冲刺、Q施放姿态与挥刀动画。
- 将剑绑定右手，保持动作接触时机与攻击判定衔接，并保留挥刀轨迹反馈。
- 由角色控制器负责位移，避免动作切换引起模型或角色位置漂移。
- 完成486项Windows自动回归，并整理工程、试玩包与素材来源，清理早期版本及重复资源。
- 在该阶段的后续文档整理中，将设计说明从流程陈述调整为设计目标、案例、取舍、亮点与验证假设的阐述。

这一版完善角色表现，并形成可以用于试玩和设计介绍的交付版本。

## v6｜三层交织动线与路线选择

**版本重点：在内容数量受限的条件下，通过到达关系、连接方式和任务先后增加丰富度。**

- 保持26个环区、既有敌人和机关种类及每房数量，重组通路与解锁关系。
- 加入四段建筑折返通道，让L1-05气密档案必须经L2-03下行进入、再上到L2-04；让L2-11回声天线必须经L3-01下行进入、再上到L3-02。
- 在L2-02提供系统支线X与货场支线Y的先后选择，两条均完成后开放共同后段。选路界面提前说明两条支线的任务差异。
- 扩展原旋转桥的用途：玩家走到原桥轴心后随桥转向，再进入非正对面的目标房间，增加可选连接组合。
- 保留已解锁通路的回访能力与完成状态，已完成遭遇不复活，并处理桥面暂停、死亡重试和静态入口检查点。
- 将三类核心装置区分为双支路电柜、管道手轮阀组和环形扫描柱，分别以轮廓和状态反馈帮助识别功能。
- 更新跨层灯带、地图、区域到达和转角衔接，并挪开与通道开口冲突的既有装置、敌人和道具。
- 同步更新9页设计PDF及两条完整Z轴路线图；最终两条路线各通过516项自动检查，Windows构建为0错误、0警告。

这一版将三层从依次清空的阶段，转为需要结合上下关系和已解锁连接理解的整体空间。

## 迭代主线

**v1 建立流程 → v2 扩展空间与挑战 → v3 改善信息可读性 → v4 修正动作与威胁 → v5 完善角色表现 → v6 深化空间与路线决策。**

记录说明：v1—v4根据保留的迭代脚本及说明回溯整理，旧版交付包已清理，未重新逐版运行。v5、v6的验证数字来自保留的对应运行报告。自动回归支持功能与通路验证，不能代替真人对手感、节奏、心流和叙事情感的评价。


## 后续修改｜配色、档案、目标提示与抑制查询

v6结构确定后，墙壁与道路调整为白色、米色，保留克制的青绿与金色引导。档案扩写了主动隔离、匮乏与最后交接的因果，并加入文档编号、来源、事件日期、摘要和已读回看。目标标记补上楼层、区号与高度方向，支线菜单说明任务链与休息位置。

功能复查中，发现蓄力抑制的64槽碰撞查询在密集场景中会漏掉扫描器。扩容重查后，失败位置能够返回全部74个目标，两条代表路线均完成26区与Boss。

视频从字幕导览发展为设计拆解与原生界面完整流程，再加入立项至成品的迭代回顾、口述解说和中文合成配音。当前视频覆盖全部26区与最终战，重点拆解的慢放另有标记。
