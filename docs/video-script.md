# 迭代回顾与解说稿

合成配音采用通用中文女声；不模仿或克隆真人。

本文章节标题按《中文展示文案规范》调整，时间码沿用已发布视频；配音正文及字幕保持同步。章节标题用于检索，不要求与已发布视频画面标题逐字相同。

## 00:00:00 立项 / 空间站背景与关卡目标

这个项目是从一个场景念头开始的：一座主动漂离家园的空间站，已经没有人回应。
我们想让玩家一路修复设备，慢慢弄清楚，为什么这里的人宁愿留下，也不肯返航。

## 00:00:17 v1 / 教学、圆环与最终战

早期先做了一层十二区的圆环，把教学、探索和最终战接起来。
那时最要紧的，是让供电、密封和抑制串成一条能走完的流程。空间变化的问题，留到下一轮解决。

## 00:00:35 v2 / 三层结构与挑战配置

单层跑通以后，关卡扩成六、十二、八区的三层。每层要考查的东西也分开了：先会用，再换个场合用，最后自己安排顺序。
高台、坡道和四类机械敌人，也让战斗有了上下之分。

## 00:00:55 v3 / 抑制技能反馈与灯带引导

内容变多，玩家却不一定看得懂。短按和长按抑制键的差别不明显，下一步该去哪里也难判断。
这一轮把范围、时长和蓄力反馈做清楚，再让流动灯带沿真正能走的路指向目标。

## 00:01:15 v4 / 高位哨兵攻击与维修机自卫

试玩还暴露出一个具体问题：上层的眼球看着在瞄准，射线却被平台挡住了。
我们调整了它的位置，保留掩体遮挡，同时补上维修机的自卫攻击。角色挥刀也开始按接触时机结算伤害。

## 00:01:35 v5 / 白模角色与攻击动画

角色随后换成现在的白色蒙皮人形，补齐持刀、奔跑、闪避和挥刀动画。
这一步主要是把动作和判定接稳，让玩家看到的攻击，和实际发生的命中对得上。

## 00:01:52 v6 / 跨层入口与支线顺序

再往后，我们给自己加了一条限制：不添房间，不加敌人和机关的种类，也不往同一间屋里堆数量。
变化从连接关系里找：有些房间要借道另一层，原来的桥开始转向，两条支线也能自己决定先后。

## 00:02:13 成品整理 / 档案、目标提示与功能修正

最近一轮收拾的是信息。档案把隔离决定、物资耗尽和最后交接的来龙去脉补了出来。
目标添上楼层和高度，抑制技能的漏响应也已修复。接下来回到成品里，看这些修改落在了哪里。

## 00:02:33 气密档案室的跨层入口

这段楼梯要去的，是楼下的档案室。
它的本层入口已经封死，只能从上层绕进来。

## 00:02:45 固定房间数量下的连接调整

二十六个房间和现有装置都保留下来。
我们改的是房间之间怎么连接，以及玩家先处理哪件事。

## 00:02:57 三层之间的完整路线

生活环先让玩家熟悉操作。到了工业环，同样的装置换了位置，也有了新的用途。
隔离环再把这些条件接在一起，要求玩家自己安排先后。
图上亮起的是这次的完成顺序。中途几次下楼，都是为了进入另一层才有入口的房间。

## 00:03:22 监视廊、气密档案与返回通道

从二层监视廊下行，读完一层的隔离授权，再从另一段楼梯回到转子校准区。
后面去回声天线时，还会再用到这套找入口的方法。

## 00:03:38 跨层通道的观察时间与引导

楼梯上没有再加一场战斗。玩家可以看清自己经过了哪层，入口又在什么高度。
目标也补上了区号和上下行方向，灯带则沿着能走通的路径继续指路。

## 00:03:55 系统支线与货场支线的顺序选择

宿舍外分成两条支线。一条要跨层查档案、做接力，另一条更集中地处理维修支援和交火。
两条都得走完，但可以自己决定先后。

## 00:04:11 安全房选路与完成状态保留

选路放在安全房里，先恢复状态，再看下一段要做什么。
做完的区域不会重置，回来认路也不用重复清场。

## 00:04:24 空箱货场 / 地面近战与高位维修支援

看这间货场：地面有近战机械体，上层还有维修机。
只追着眼前的敌人打，维修机就会不断把同伴修回来。

## 00:04:36 沿坡道接近上层目标

坡道把上层的维修机变成了能接近的目标，登台途中仍然会暴露。
可以先清近战，也可以抓机会先拆支援。要比较的是眼前的危险，和继续拖下去的消耗。

## 00:04:54 战斗后的出口供电

解除威胁后，再把电切给出口。
这一间没有增加机关，变化来自动手的先后，以及接近目标的路线。

## 00:05:06 旧版 / 档案事件信息不足

旧档案留下了情绪，却没有交代清楚：谁决定隔离，最后又要交接什么。

## 00:05:14 新版 / 档案来源、时间与已读回看

现在先用摘要说清这份文件记录了什么，再补上来源、日期和正文。
读过的档案可以随时回看。即使先走另一条支线，也能把事件的先后对起来。

## 00:05:30 旧版 / 距离提示缺少楼层信息

在多层空间里，只给一个距离，玩家还是不知道该从哪层过去。

## 00:05:38 新版 / 楼层、房间与高度提示

所以目标添上了楼层、房间和高度方向。
复杂的连接保留下来，但需要的信息也得一起给到玩家。

## 00:05:54 封存名单的读取条件

这些名字要先稳定舱压、抑制干扰，才能从终端里取出来。
读到这里，前面的维护就有了一个具体的去处：把居民留下的记录传回家园。

## 00:06:10 最终交接与空间站隔离

守门者还在执行禁止离站的命令。解除防卫后，发送的只是档案和姓名。
空间站仍留在深空，隔离并没有解除。

## 00:06:24 跨层往返与空间记忆负担

跨层越多，记路和往返的负担也越重，所以只把关键任务放进这几个回路。
安全房里选路，完成区保留进度，都是为了少添一层额外的负担。

## 00:06:40 九处安全房的恢复、阅读与选路

九处安全房穿插在交火和连续操作之间，两条支线也各有安静的收尾。
玩家可以读档案、回看楼层关系，想好下一步再出发。
