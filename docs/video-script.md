# 迭代回顾与解说稿

合成配音采用通用中文女声；不模仿或克隆真人。

## 00:00:00 立项 / 空间站背景与关卡目标

立项时确定了三个部分：线性教学、环状探索和圆形最终战。背景是一座为隔离感染而主动离开航线的空间站。
玩家需要恢复设备、收集档案。关卡要交代居民为什么选择隔离，以及留下之后经历了什么。

## 00:00:22 v1 / 教学、圆环与最终战

第一版采用单层十二区圆环，先接通教学、区域任务和最终战。
供电、密封和抑制各有明确结果，后续房间再要求组合使用。这一阶段主要检查任务能否连续完成。

## 00:00:41 v2 / 三层结构与挑战配置

第二版扩为六、十二、八区的三层结构，分别安排单项操作、条件组合与综合运用。
四类机械敌人配合高台和坡道，要求玩家同时留意地面近战、高位射线和维修支援。

## 00:01:01 v3 / 抑制技能反馈与灯带引导

试玩中，短按和蓄力抑制的区别不够明显，下一处任务也难以辨认。
这一版补充蓄力进度、作用范围和持续时间反馈；流动灯带沿实际可通行路径，指向当前操作点或出口。

## 00:01:20 v4 / 高位哨兵攻击与维修机自卫

上层哨兵曾出现预警正常、射线却打不到人的问题，原因是光束被自身平台挡住。
调整到平台前缘后，射线可以覆盖下层，实心掩体仍能阻挡攻击。维修机也补充了无修复目标时的自卫射击。

## 00:01:42 v5 / 白模角色与攻击动画

角色更换为白色蒙皮人形，接入持刀、移动、闪避和挥刀动画。
角色控制器负责位移，攻击按接触时机结算，避免模型动作和实际命中脱节。

## 00:01:59 v6 / 跨层入口与支线顺序

第六版保留二十六个环区，不增加敌人、机关种类，也不增加单房配置数量。
调整集中在连接关系：两间房只能跨层进入，中央桥支持轴心转向，工业环的两条必经支线可以交换顺序。

## 00:02:19 成品整理 / 档案、目标提示与功能修正

后续修改补充档案来源、事件日期与摘要，说明主动隔离、物资匮乏和最终交接之间的关系。
目标显示楼层与高度方向，抑制查询漏响应也已修复。下面结合完整路线和货场实例，说明这些设计的用途。

## 00:02:42 气密档案室的跨层入口

气密档案室位于生活环，本层入口封闭，需要从工业环下行进入。
因此，目标所在楼层和入口所在楼层必须分开判断。

## 00:02:56 固定房间数量下的连接调整

这一轮保留二十六个环区和既有装置，主要调整房间连接和任务顺序。
设计目标是在固定内容中增加找入口、选路线和安排操作的判断。

## 00:03:12 三层之间的完整路线

生活环介绍单项操作，工业环改变装置位置与用途，隔离环要求组合前置条件。
路线中穿插两次下行取档，再从另一段通道返回。楼层不再对应单一的推进阶段。
图中按路线甲点亮全部二十六区；两条支线完成后汇入共同后段，最后进入控制舱。

## 00:03:40 监视廊、气密档案与返回通道

从工业环监视廊下行到气密档案室，读取隔离授权，再经另一段通道返回转子校准区。
后段的回声天线沿用跨层入口规则，并加入继电器接力和限时出口登记。

## 00:03:58 跨层通道的观察时间与引导

跨层通道不追加交火，留出观察高度和确认来路的时间。
目标标注房间与上下行方向，灯带沿折返坡道指路，地图补充两层之间的连接。

## 00:04:14 系统支线与货场支线的顺序选择

系统支线包含监视廊、跨层档案和转子接力；货场支线集中安排近战与维修支援。
两条都必须完成。玩家选择的是任务先后，不会漏掉另一条的内容。

## 00:04:31 安全房选路与完成状态保留

选路界面放在休眠宿舍。玩家恢复生命和技能后，可以比较两条任务链。
已完成区域保留状态，回来查看地图或档案，不需要重复清场。

## 00:04:47 空箱货场 / 地面近战与高位维修支援

空箱货场的近战机械体在地面，维修机在上层恢复同伴。
维修支援持续存在时，只攻击地面目标可能延长战斗，因此要判断何时登坡。

## 00:05:03 沿坡道接近上层目标

坡道提供接近维修机的路线，登台途中也会暴露。
先处理近战可以降低登坡压力，优先拆维修机则能中止支援。取舍取决于当前威胁与可用的接近机会。

## 00:05:20 战斗后的出口供电

解除威胁后，将电力切到出口支路，完成本区任务。
战斗与供电沿用已有规则，高差和维修关系改变的是接近路线与目标优先级。

## 00:05:36 旧版 / 档案事件信息不足

旧档案较短，居民为何隔离、物资如何耗尽、最后交接什么，交代得不够完整。

## 00:05:45 新版 / 档案来源、时间与已读回看

新版以摘要说明文件内容，编号、来源和日期用于关联事件，正文保留细节。
已读档案可以回看。支线先后变化时，玩家仍能通过事件日期核对叙事顺序。

## 00:06:03 旧版 / 距离提示缺少楼层信息

多层空间只提示直线距离，无法说明入口在哪一层。目标即使很近，也可能需要绕行。

## 00:06:13 新版 / 楼层、房间与高度提示

新版同时显示楼层、房间和高度方向，灯带负责指出眼前可走的路径。

## 00:06:32 封存名单的读取条件

封存名单需要稳定舱压并抑制扫描，才能从终端读取。
维护操作直接决定叙事资料能否取得，玩家的任务也从恢复设备推进到传回居民姓名。

## 00:06:48 最终交接与空间站隔离

守门者仍在执行禁止离站的命令。解除失控防卫后，发送档案与姓名。
本次仅传输数据，不运输人员或机械载体，空间站继续保持隔离。

## 00:07:05 跨层往返与空间记忆负担
