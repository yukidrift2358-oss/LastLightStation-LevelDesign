# 文案、配音字幕与游戏文本修订

依据《中文展示文案规范》修改章节标题、设计讲述、完整流程解说、配音、字幕与游戏内文本。将“看得懂，才能继续走”等标题改为“抑制技能反馈与灯带引导”，正文直接说明操作、条件、结果和设计取舍。

游戏内更新26区操作提示，修正货场支线包含温室的错误：货场支线为货场、装卸区与影院，温室属于两支线完成后的共同后段。档案保留编号、事件日期、来源与摘要，将混入正文的策划说明改为站内记录。种子样本留站，栽培数据与居民档案纳入信息发送，避免与隔离设定冲突。

完整流程重新采集，保留原生界面和正常操作速度。讲解稿重合成98段语音并生成同步字幕，画面标题一起修改；章节标签与字幕分行排在游戏画面下方。三段局部慢放继续标注。旧版成片保留。

两条代表路线完成26区与Boss；每房对象数量与v6基线一致。仅修改显示字符串，未调整玩法数值、关卡结构或任务条件。正常试玩包从主工程单独构建，不包含录制控制工具。检查结果用于确认功能和文本呈现，不作为真人探索或平衡性测试结论。
