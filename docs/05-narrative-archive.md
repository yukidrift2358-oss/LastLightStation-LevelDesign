# 叙事档案与任务因果

叙事链：调查任务 → 主动隔离 → 匮乏与失控 → 姓名存证 → 纯信息交接。事件时间与浏览顺序分离，兼容两种支线次序。

## SW-ARC-L1-01 / 失联调查
隔离纪元 D+185｜站务值班组
接续任务：重建隔离事件经过，汇集居民记录。

隔离后的第185日，值班系统仍在自动生成交接单，人员签到一栏却连续空白。最后一位值班员没有签退，只把任务改成了“等待后来者接班”。

远程调查只能收到防卫系统的应答，无法确认居民去向。你被派来恢复维护通路、读取原始档案，并把能够带走的信息传回家园。站上仍在运作的机器不代表这里还有人。

## SW-ARC-L1-02 / 配给缩减
隔离纪元 D+028｜生活保障组
配给耗尽并非突然发生，而是长期隔离的结果。

补给航线切断后的第28日，食堂把全份餐改成半份；第43日，领取凭证开始只登记饮水量。库存计算没有等来下一艘运输船。

配给牌背面的手写备注是：“给孩子的那份保持原样，差额从成人夜班里扣。”低压泄漏又让取餐区无法使用。关闭眼前的隔离阀，才能安全读取剩下的交接记录；修好设备，也已经无法补回缺失的食物。

## SW-ARC-L1-03 / 识别规则
隔离纪元 D+047｜防卫维护组
防卫装置把维修人员也纳入了感染风险。

自卫系统原本负责拦截未经检疫的机械载体。第47日，识别库受到污染，工人使用的维修外骨骼被标记为感染目标。

维护组请求解除武装，但隔离协议禁止远程覆盖。训练靶场被临时改作避难点，冲锋程序却仍照常运行。设备还记得如何攻击，已经无法理解为什么有人走进这里。

## SW-ARC-L1-04 / 自主放逐
隔离纪元 D+000｜航行控制组
空间站由居民主动推离航线，以保护家园。

感染确认当日，站方提出切断航路并自行变轨。居民共同授权后，推进器把守望站送向远离家园的深空，避免感染随救援或返航扩散。

这不是一次被取消的撤离，而是一次主动执行的隔离。观景台保存了每次轨道修正：家园的光点越来越小，隔离仍没有结束。授权原件存放在生活环气密档案室，其本层入口已被永久封闭。

## SW-ARC-L1-05 / 共同授权
隔离纪元 D+000｜居民代表联署
隔离命令由居民签署；上层检修道是剩余入口。

原件载明：在无法排除感染外泄之前，停止客运、物资外运及任何载体离站。签名来自居民代表、医疗组与航行值班员，命令并非由远方强加。

混乱发生后，生活环直达入口被焊死，工程组保留工业环监视廊通往此处的下行检修道；读取后可经另一段步道返回转子校准区。绕行保护的是档案与隔离边界。居民授权隔离，却没有授权自己的名字被抹去。

## SW-ARC-L1-06 / 维护替班
隔离纪元 D+063｜机械维护组
无人检修仍在继续，人员却已逐渐退出值班。

第63日，维护工把自己的休息时段划掉，换成供水机械的保养时间。日志反复出现“人可以再撑一班，泵不能停”。

后面的记录改由机械体自动提交，连续写着“工位无人，等待授权”。最后一条人工备注要求停用主动追踪程序，只保留巡检。该舱段已停用武装巡检，可供接班人员休整。检修终端仍保存着前一班的维护结果。

## SW-ARC-L2-01 / 回路维护
隔离纪元 D+074｜净水工程组
修复接力保障供水，先隔离泄漏以免回路重置。

滤芯已经超过更换周期十一次。维护组用不同型号的旧部件拼成临时净水回路，只能按标牌顺序逐段启动。

泄漏未关闭时，压力波动会使接力失败，因此必须先密封再通电。日志末尾写着：“今天修好，今晚每人可以多喝一口。”这套看似繁琐的维护顺序，曾经决定整层居民当天能领到多少水。

## SW-ARC-L2-02 / 生日留言
隔离纪元 D+081｜生活环私人备份
支线都需恢复；先完成哪一条，由接班者安排。

宿舍终端保存着第81日的生日留言。前半段有人模拟点蜡烛的声音，后半段谈起净水滤芯和越来越少的口粮，没有人再提下一次庆祝。

值班员在留言旁附上维修交接：系统X包含跨层档案、监视与接力；货场Y包含维修支援、近战与温室保障。两条都需恢复，完成顺序可以自行决定。休息后再出发，已经完成的工作不会因为回访而丢失。

## SW-ARC-L2-03 / 异常指令
隔离纪元 D+047｜防卫控制组
遮挡可以阻断射线，接入B电前先确认交火位置。

安全指令被改写为“所有仍能移动的物体均需复检”，却没有留下通过复检的有效流程。红色镜头仍在守卫一条已经无人申请使用的走廊。

维护员记录：实心隔墙能够阻断射线，暴露后应观察蓄能预告再转移。出口与防卫设备共用B支路，切换电力前应处理现有威胁。此处另有下行档案检修道；那份授权能够解释系统为何一直拒绝开放返航。

## SW-ARC-L2-04 / 时间失准
隔离纪元 D+090｜转子维护组
高位接力需要抑制窗口，转子停机也使日夜消失。

转子故障后，生活环的模拟晨曦停在同一时刻。居民改用广播报时，后来广播也只能播放预录的整点提示。

检修员把校准点留在高位步道，避免底层转动结构触及接口。读取标牌、接近操作点，再用抑制窗口完成接力，比在底层反复试按更可靠。日志最后问：“如果灯再也不暗，明天还算不算到来？”

## SW-ARC-L2-05 / 负载取舍
隔离纪元 D+102｜配电工程师
有限能源优先维持医疗与档案发送，无法恢复全站。

三条主供电回路已无法同时运行。工程师逐项划去影院、模拟晨曦和运输待机负载，把剩余功率留给医疗舱。

备用方案不是修复一切，而是在最后一次交接时，为记录发射器保留一分钟。维护区保留应急恢复设备；这份余量来自其他系统的停机，不代表空间站已经恢复正常。

## SW-ARC-L2-06 / 支援链
隔离纪元 D+109｜物资调度组
维修机会恢复同伴，优先处理它可以终止反复交火。

货单记录了最后一次物资分配：医疗箱先送隔离环，其余居民继续等待。仓库里留下相同型号的空箱，调度系统却仍把它们识别为“待装货”。

感染后的维修机继续执行修复任务，连失控的自卫设备也被当作维护对象。高位步道提供接近支援目标的路线；如果只处理正面的机械体，修复链会拖长交火。货物已经用尽，维护命令仍在相互维持。

## SW-ARC-L2-07 / 停映通知
隔离纪元 D+116｜公共文化终端
影院停映后让渡电力，放映终端仍保存最后一帧。

影院最后一场放映是一段海边录像。停映通知写着：“非必要用电即日起让渡医疗组，恢复日期另行公告。”

座椅没有清空，银幕也保留着最后一帧。本站已撤销影院内的武装巡检；维护人员可在此查看记录、使用应急恢复设备，或继续前往下一工位。居民当时仍把停映视作暂时的安排。

## SW-ARC-L2-08 / 种子保留
隔离纪元 D+123｜温室培育组
把最后的粮食留作种子，是对后来者的托付。

温室组没有煮掉最后一袋可播种的谷物，而是将它分成栽培与封存两份。栽培槽随后缺水，幼苗没有等到成熟。

工程记录要求先隔离泄漏，利用A支路读取种植数据，再把电力交给通路。封存样本已转移到隔离环种子冷库。留下种子的人知道自己可能等不到下一季，仍希望某一天有人能把它带到有水和土壤的地方。

## SW-ARC-L2-09 / 无人转诊
隔离纪元 D+132｜医疗值班组
名单停止增长，因为再没有人能够送来下一位患者。

医疗登记停止更新时，所有病床并没有突然空出。最后一位护理员写道：“还有人在其他舱段，但今天已无人能把他们送来。”

输送通道需要在抑制窗口内登记，超时只需等待冷却再次尝试，已经密封和留档的状态不会撤销。维护这套流程曾是争取救治时间；如今记录保留下来，让这些人的离去不再只是一个没有说明的数字。

## SW-ARC-L2-10 / 家园坐标
隔离纪元 D+141｜航行观察员
升降台连接工业环与隔离环，部分任务需借道下层。

观景终端每年都更新家园坐标，隔离后的观测精度却越来越差。值班员仍在每次更新后写下同一句话：“看不见，也要记住它在哪里。”

这座升降台连接工业环与隔离环。观察窗可以看见两层外缘及已经恢复的维护通路。请注意：隔离环部分工位仍需借道工业环进入。下一段要重新借道工业环，取回无法由隔离层直达的天线记录。

## SW-ARC-L2-11 / 姓名信号
隔离纪元 D+153｜通信值班组
居民不再请求载体返航，只希望姓名能够传回去。

求救信息曾被离站协议逐封拦截。通信员最后改写了发送内容：不申请救援、不请求靠泊，只发送居民姓名和隔离事件经过。

发射回路仍需接力与短时抑制共同恢复。这处天线从隔离前室下行进入，完成后经另一段步道回到磁轨回廊。居民想保护的边界仍在；接班者需要解除的是阻止纯信息交接的失控执行。

## SW-ARC-L2-12 / 最后物资
隔离纪元 D+150｜装卸班组
同伴修复与近战威胁需要在同一次交火中安排优先级。

最后一批物资已经分发完毕，自动货单仍每天追加“装卸中”。没有人有权限结束整条调度队列。

受感染的机械体在空箱间继续巡回，维修机把损坏目标不断恢复。抑制可以暂时中断威胁，掩体则用于重新组织接近路线。它们争夺的已经不是货物，而是一条失去人员监督、仍在无限延续的工作命令。

## SW-ARC-L3-01 / 协议边界
隔离纪元 D+001｜隔离控制组
密封、B电、抑制依次成立，才允许出口登记。

隔离控制协议规定：先确认舱压边界，再接入通路电源，最后验证扫描停止窗口。任何一项缺失，都不允许打开人员通道。

最初这套程序是为了避免感染穿越气密边界；失控后，它只会机械地拒绝一切通行。眼前的操作顺序因此不是任意排列的密码。完成前室后需要下行至回声天线，隔离层本身没有可直接抵达该终端的入口。

## SW-ARC-L3-02 / 循环任务
隔离纪元 D+159｜磁轨检修组
先读牵引预告，用柱体打断强制位移。

运输列车停了，磁轨却仍在把空托盘送往食堂。系统无法确认居民是否已领餐，于是不断重试同一条配送指令。

牵引装置的预告标记会先于拉拽出现，柱体可以阻断作用。维修员曾建议停机，但禁行协议把这条请求标记为“影响生存保障”。本来为了照顾居民留下的系统，最终连无人领取都无法理解。

## SW-ARC-L3-03 / 最终交接
隔离纪元 D+185｜末班值守员
解除守门者后，发送记录与姓名，不开启载体返航。

最后的值守员把椅子转向气闸，留下交接内容：“如果有人抵达，请确认隔离仍有效，把记录和名字带回去，不必再来接我们。”

全部维护区留档后，外侧航行控制舱开放。守门者仍执行禁止任何载体离站的末班协议，需要用已学的供电、密封与抑制解除其失控防卫。交接完成只发送信息，空间站继续留在深空，不将尚未确认安全的载体带回家园。

## SW-ARC-L3-04 / 姓名存证
隔离纪元 D+178｜居民共同备份
名单保留二十六个值班席位的签名，并非全站人口统计。

名单保留了二十六个值班席位对应的姓名与代签痕迹，它不是全站人口统计。有人失去书写能力后，由邻居补上了签名。

末页写着：“我们住过这里。请在记录里保留这一点。”文件被气密与扫描双重封存，取回前需先稳定舱压并抑制干扰。校验完成后，文件将加入最后一次发送队列。接班者可以回看这些签名，核对他们曾在这里共同生活的痕迹。

## SW-ARC-L3-05 / 发送预案
隔离纪元 D+172｜配电工程师
先隔离再接力，把有限电力留给最后一次发送。

工程师计算了记录发射器的最低负载，拆去返航与非必要设备的预算，留下三条必须按顺序建立的供电支路。

先关闭泄漏以稳定负载，再完成继电器接力，才能把B支路接给后续通路。这份方案无法使空间站重新启航，只能让记录在最后一次交接时有机会离开。工程师把它命名为“遗嘱”，因为届时自己也许已经无法按下发送。

## SW-ARC-L3-06 / 返航不可行
隔离纪元 D+176｜航行演算组
撤离演算失败没有否定发送信息的可能。

演算组尝试过避开感染传播的撤离方案。每一次模拟都无法同时满足乘员存活、载体安全和家园不受污染三个条件。

操作员没有删掉失败记录，直到最后仍在调整参数。信息发送不运输人员或机械载体，与返航适用不同风险边界。观景步道旁保留这些结果，是为了让后来者理解居民为何留下，而不是把他们的选择误读为从未尝试。

## SW-ARC-L3-07 / 禁止离站
隔离纪元 D+180｜防卫控制组
关闭支援链，解除守门者对隔离协议的失控执行。

末班命令仍写着“禁止任何载体离站”。感染后的防卫系统把维护人员、通信回路和逃离行为归为同一种风险，拒绝接受新的任务解释。

先利用断电与遮挡控制射线，再处理维修支援，可以避免反复消耗。最终控制舱中的守门者沿用相同错误：它保留了隔离的形式，却把保护对象和执行目的都遗忘了。需要解除防卫，才能完成居民留下的纯信息交接。

## SW-ARC-L3-08 / 下一季
隔离纪元 D+124｜温室培育组
冷库保留的是种子与栽培数据，留给能够接班的人。

冷库里没有可立刻食用的补给，只有干燥种子和经过筛选的栽培数据。标签注明：“不要为我们打开；带到能够种下它们的地方。”

高位步道通往封存终端，取回这份记录后即可离开。冷库安保已停用，封存与保温仍在运行。居民留下的不只是匮乏的记录，还有一份指向未来的安排。下一季不属于守望站，可能属于收到交接的人。
