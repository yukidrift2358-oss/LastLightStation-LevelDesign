# 项目概览

## 立项目标与基本结构

空间站已经沦陷，但设备仍在重复执行旧任务。关卡需要让玩家从设备功能与生活遗留物里，读懂居民主动隔离后的处境。基础结构是线性教学、环状主体和圆形最终战。

## 内容数量约束与空间调整

主体扩展为6/12/8三层后，后续丰富度不再依靠新增房间、敌人或机关种类，也不增加单房数量。设计转向上下层的入口依赖、桥梁可达关系和支线先后选择。局部高差改变接近成本，安全房给玩家恢复与重新计划的空间。

## 视频、试玩包与设计文档

完整视频保留原生界面和操作反馈；重点展示单独解释跨层回路、空箱货场的维修支援、档案与指引的修改。Windows包可以直接试玩，Unity工程提供当前场景与代码。结构、版本顺序、后续叙事和验证证据分别列成文档，方便按关心的问题查看。
